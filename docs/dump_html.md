### Save already loaded tab

You can archive page not only by URL, but with HTML string too. For this you need to install extension from `extension` dir.

It will take URL and HTML of the page and archivize it. Assets will be downloaded from original anyway, so archived version may suffer if the original site is SPA or has Anti-DDoS.

To avoid issues from archived version, all the JS of the page are deleting by default.
